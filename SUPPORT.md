# Support

1. Read [Getting Started](GETTING_STARTED.md) and [Troubleshooting](TROUBLESHOOTING.md).
2. Run `npm run doctor` from the package checkout.
3. Search existing GitHub issues.
4. Open a bug report for reproducible defects or a feature request for proposals.

Security problems must use [private vulnerability reporting](SECURITY.md), never a public issue.

Include:

- extension version or commit
- Prime/pi version
- OS and architecture
- terminal and tmux status
- Node and uv versions
- `/voice status`
- selected preset, compute device, and microphone
- sanitized doctor output

Remove usernames, local paths where sensitive, tokens, audio, transcripts, settings, and raw debug logs. Problems originating in Prime, Moondream/Kestrel, operating-system audio, or terminal keyboard protocols may be redirected upstream.
